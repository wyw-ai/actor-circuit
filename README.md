# Open Multi-Actor Protocol

An emerging vocabulary for reasoning about collaboration among Humans, AI Agents, Services, Scripts, Teams, Workflow instances, and External Systems.

The project currently organizes the problem into three layers:

- **L0 — Collaboration Logic Circuits:** defined in the current release.
- **L1 — Multi-Actor Communication Protocol:** boundary defined; specification forthcoming.
- **L2 — Multi-Agent Systems:** boundary defined; system taxonomy forthcoming.

## Skill

[Actor Circuit](skills/actor-circuit/SKILL.md) gives an AI Agent the L0/L1/L2 vocabulary for understanding, explaining, designing, and reviewing Multi-Actor collaboration.

The first release intentionally provides semantic references rather than a fixed workflow, script, CLI, or machine schema. It assumes a capable Agent and supplies the domain model the Agent does not already have.

The underlying workflow and interaction structures are not claimed as original inventions. This project abstracts and organizes established ideas and engineering experience around a common Actor boundary.
